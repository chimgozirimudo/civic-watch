# CivicWatch

## Project Goal
A web application that allows citizens to report civic issues in their communities and track the progress of those reports.

## Roles

### Citizen
- Register
- Login
- Report issues
- Upload images
- View only their own reports
- Track report status

### Admin
- Login
- View all reports
- Update report status
- Manage reports

## Core Features
- Authentication
- Report issue
- Upload image
- Add location
- Track status
- Deploy
